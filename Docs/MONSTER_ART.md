# 怪物三视图、模型与特效资源

本轮沿用英雄的“三视图参考 → Blender分部建模 → UE导入 → runtime加载”流程。原始设定为 `SourceArt/Monsters/References/AnimeMonsterTurnarounds.png`，离线FBX回导预览为同目录 `ModeledMonstersPreview.png`。两者用途不同：前者是动漫设计目标，后者是本轮实际网格，不是UE截图。

| 类型 | 模型辨识 | 释放效果 |
| --- | --- | --- |
| 赤铁鬼刀兵 | 双角面具、肩鳞与胸鳞、赤衣和弯刀 | 弧形刀光、火星 |
| 琥珀盾卫 | 宽甲、独立八角盾、发光圆封印 | 盾击震波、短地爆 |
| 靛蓝火铳傀儡 | 鸟喙面罩、尖兜帽、长衣、蓝色背罐 | 枪口焰、短弹道 |
| 熔炉鬼将 | 鬼面、炉心、双烟囱、方形巨锤 | 横扫刀光、地面火线、锤击爆炸/碎石/烟尘 |

共33个FBX（四种各8分部加盾卫独立盾），保留原程序动画pivot及既有攻击数值。模型导入检查语义材质槽、厘米单位与逐轴包围盒；资源缺件时整套回退已有怪物模型/武器，并输出警告。盾牌守势姿态与颜色、枪手前摇危险线保留。模型属于原创分部低模，尚非手工精雕、骨骼蒙皮、独立肘膝动作或布料模拟。

`SourceArt/MonsterEffects/T_MonsterEffects.png`为原创生成的1254平方RGBA透明图集，四格依次是刀光、地爆、火线、烟尘。UE脚本生成四个Masked Unlit材质；每个攻击效果最多两张无碰撞贴图卡片，配合已有有限数量的实体光弧/火星/碎石。普通怪物与Boss效果在真实释放事件后播放，取消前摇不产生释放效果；不改变权威伤害。具体同步和预算见 `MONSTER_EFFECTS.md`。

## 使用

关闭UE，拉取源码和LFS网格，然后运行原构建入口：

```bash
git pull --ff-only
git lfs pull
./Scripts/Build-Mac.sh "/Users/Shared/Epic Games/UE_5.6"
```

Windows沿用 `Scripts/Build-Windows.ps1`。集成资源报告版本为2，核对英雄、怪物、背景与特效共63个保存资产；普通Editor启动也会按源指纹更新。新生成资源在`/Game/Art`，沿用现有Cook目录。需要重新建模才需要Blender，导入已有FBX不需要安装Blender。脚本不会覆盖非生成器所有的同名资产。

## 验证与待验收

本轮战斗222、表现320、敌人375、操作1174，共2091项可移植检查及各自UBSan通过；检查脚本验证三视图与VFX PNG源SHA-256/尺寸、33个真实FBX。Blender官方FBX解析和回导检查节点无100倍缩放、无意外旋转平移，边界与厘米manifest一致。没有运行UE编译、Python导入API、shader编译或实际联网。

实机重点：

1. 三类普通敌人与Boss均显示新模型；盾卫守势收盾不丢材质，枪手衣服/能量与其它怪有明显区别。
2. 刀兵起手无刀光，真正挥出才出现；起手时打断/击杀不出现释放特效。盾卫破势行为保持原样。
3. 枪焰来自枪口且只播一次，危险线仍在前摇阶段显示；侧面和反向攻击时弹道方向正确。
4. Boss横扫、火线、锤击分别可辨；高台/坡面爆炸贴地，没有悬空震波或预警被遮住。
5. 三人混战、远镜头、小窗口检查贴图卡片无黑色矩形、不挡关键预警；打包后材质与网格完整。UE Automation与真实LAN仍需独立验收。
