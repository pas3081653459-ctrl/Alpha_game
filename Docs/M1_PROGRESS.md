## 本轮已实际执行的可移植测试

`python3 Scripts/run_rules_tests.py` 使用 `g++ -std=c++17 -Wall -Wextra -Werror -pedantic` 编译 `Scripts/test_rules.cpp`，随后运行测试，编译与执行产物位于临时目录，退出码传回调用方。

本轮执行结果：**222 / 222 条检查通过**。另以 UndefinedBehaviorSanitizer 编译同一测试并执行，222 / 222 通过，无 UBSan 报告。

覆盖内容：

- 敌人伤害、友伤、无敌、死亡、负伤害、零伤害与超量伤害。
- 精确架势破防、死亡时不触发破势、非有限数与非法上限。
- 救援七项条件分别取消、精确完成、超时钳制、负时间与非有限时间。
- 倒地次数与人数的整数极端边界，波次数量和 Boss 生命缩放。
- 冷却精确边界、不同玩家跟进窗口、合作冷却和未来/非有限时间。
- Boss 圆形、矩形、扇区几何，半径/角度/宽度/长度/高度边界，平移、旋转、无效方向、每轴非有限值和极端有限坐标。

测试直接调用 `Source/AlphaGame/Rules/CombatRules.h`。这些函数在 UE 战斗、救援、能力、波次或 Boss 代码中实际使用，不是额外复制的测试实现。边界测试期间发现并修复了先减法后钳制造成的潜在有符号整数溢出。

上述结果只验证纯规则；没有验证 Unreal 组件注册、委托、计时器、网络复制、伤害扫掠、UI 或图形输出。

## 独立审查与剩余风险

- 已交叉阅读角色、战斗、救援、能力、波次、Boss、连接入口和恢复逻辑。
- 同步状态在权威端决定，客户端不能通过请求直接提交伤害值；这仍需联机测试证明集成行为。

- 三人高频攻击下的 Boss 硬直、技能节奏和可读性仍需真实运行验证。
- 战斗和间歇中拒绝热加入，人数缩放锁定于开局；掉线玩家需要等待准备或结果阶段再加入，未实现战斗内重连恢复。

- 无自动房间发现、房主迁移、正式角色/关卡资源、声音、完整保存和设置系统。
