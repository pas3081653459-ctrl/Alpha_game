# 动漫角色与战斗表现增量

## 风格与证据

按最新要求，美术目标为日本热血战斗动漫：清晰色块、夸张姿态、亮芯刀光、速度线和冲击爆发。保留归炉城、工坊和三角色身份，早期偏工业写实的说明不覆盖本方向。

本轮修改为程序化角色、动作、网格特效、材质生成与权威判定源码。云环境没有 Unreal，未运行材质生成、UHT/UBT、渲染或实机输入。不能把本轮交付称为正式手工角色模型、骨骼动画、完整音效或最终画面。

## 材质

`Scripts/create_art_assets.py` 更新自有生成材质：

- `M_AlphaSurface`：保留 DefaultLit 动态光照和阴影，用固定方向法线计算叠加三段明暗，并加入边缘提亮。`AnimeShade` 控制强度；不是对实际场景动态阴影进行量化的 Toon Renderer。
- `M_AlphaEffect`：独立不透明 Unlit 能量材质，控制亮色形体与发光；关闭 Bloom 仍保留色块。实体网格通过缩放与寿命退出，不依赖透明叠层。
- 两张原始纹理继续使用；生成后应有两个材质、两张纹理共四个 `.uasset`。Windows 包装脚本检查本次报告与四资产。

没有生成材质时使用引擎基础颜色回退，不具备完整分段着色或 Unlit 发光。Mac 在编译后打开 UE 编辑器，通过编辑器的执行 Python 脚本入口运行 `Scripts/create_art_assets.py`；保存后重启编辑器，清理本次进程的回退材质缓存。不应手工覆盖生成器管理的资源，需要编辑时先复制。

## 人物、刀光与技能

沈砚强化红头带和尖发，阿绫增加马尾，闻灯保留灯环与长衣轮廓；眉线、鬓角、头发与腰带使用每角色一个额外ISM批次。角色使用较强分段明暗、提亮服装，并增加攻击时身体扭转、空中收腿和三职业施法姿态。仍使用基础几何，没有骨骼绑定资产。

刀光由职业色外层与朝相机的白色表面亮带组成；亮带位于实体外侧，避免被不透明外层遮住。地面与空中连招使用不同轨迹，技能使用九种职业/槽位组合，范围从同一共享表读取。地面冲击包括扩散环、爆炸星芒、短时发光裂纹与弹道碎屑，约0.85秒清理；不是永久裂地贴花。

每效果最多24片外层与24片亮带，两个ISM批次，共48实例；单世界最多24效果，保留受击、破势及救援的较高优先级。镜头冲击遵守原有震动开关。需要实测三人混战性能，不将代码预算直接当作帧率结论。

## 空中变招与地面冲击

空中 J 五段独立于地面数据：下弧斩、反向轮斩、上挑交叉斩、俯冲刺与陨落终段；判定中心下移、纵向覆盖扩大，可触及脚下普通敌人。第3段确认命中后挑起非 Boss 敌人，不能借此搬运 Boss。仍保留同次离地最多3.2秒滞空、受击/翻滚/施法取消和重力恢复，没有增加空中无敌。

第五段从面前真实射线检测地板，只有检测到可行走朝向的静态表面且视线畅通才产生冲击；地面半径235cm、空中半径285cm，向下检测分别最多210cm/520cm。挥击与冲击共用命中集合，同一目标本次只受一次伤害。冲击反馈来自权威事件，不是视觉自行决定是否命中。暂不包含任意可移动平台或全地形物理破坏。

## 环境交互

场地增加八个可击碎箱子，普攻、技能及地面冲击在实际结算时可击碎范围内道具。破坏由服务端决定，检查来源阵营、存活、范围和视线，复制破坏状态；后加入者不会重播旧爆发，重开恢复道具。箱子没有移动碰撞，不阻挡角色、不增加伤害、不掉落资源。

此交互不是 Chaos 全场景破坏、永久地形变形或物理碎片伤害。碎屑与地面反馈只承担表现。

## 实机验收

1. 构建编辑器，生成材质并重启，检查三个角色的轮廓、武器、衣摆与明暗。
2. 对着敌人及空地连续按 J，检查五段轨迹与有效判定时刻；翻滚、施法、受击应取消尚未发生的刀光。
3. 跳跃后从不同高度连按 J，检查独立空中变招能覆盖下方目标；墙体不能被穿透，Boss 不应被普通挑空搬运。
4. 第五段检查只有检测到地面才出现地面冲击；空中挥击和地面伤害不能对同一目标重复结算。无地面时不应凭空爆炸。
5. 攻击八个箱子，确认破坏、重开恢复和客户端状态一致；箱子不能造成卡位。
6. 三职业分别施放 U/I/O，检查方向、范围、颜色差异和能量消耗；终极不得遮住 Boss 危险预警。
7. 设置 `CameraShakeStrength 0`，冲击时不能有镜头震动；关闭 Bloom、使用低画质仍可识别刀光和预警。
8. 三人连续混战、重开，检查效果对象数量、帧时间、复制与清理；Development/Shipping 包分别验证资产加载。

上述 UE 项目均待实际执行；纯 C++ 规则通过不能替代视觉和手感验收。
