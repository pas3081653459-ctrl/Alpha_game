# 玩家操作与战斗规则

## 本轮控制约定

| 输入 | 行为 |
|---|---|
| W / A / S / D | 在完整 XY 平面移动，角色面向实际移动输入方向；松开后保留朝向 |
| 同方向双击 | 两次按下间隔不超过 0.28 秒且中间确实松开时进入 2.5 倍奔跑，伴随视觉反馈 |
| J | 五段循环普通连招；空中也可攻击；第五段结束前有受限滞空 |
| K | 跳跃，可躲开满足高度条件的地面攻击 |
| L | 沿当前面向翻滚，不依据与面向不同的残留移动速度决定方向 |
| U | 成功施放后增加 10 能量，封顶 100 |
| I | 成功施放消耗 10 能量，不足时拒绝 |
| O | 仅满 100 能量时可施放，消耗全部 100 |
| E / Tab | 保留救援与房间面板，菜单打开时不触发战斗动作 |

能量初始为 0；普通攻击命中不增加能量。旧的普通/合作命中奖励不能绕过新能量约定。施法失败、仍在冷却、死亡或硬直等拒绝情况不应修改能量。

奔跑判定同时要求两次按下间隔不超过 0.28 秒与中间明确的释放事件，不能把系统按键重复当第二次点击。长按一秒后松开并立刻再按，不属于双击。同方向与方向切换的行为应一致且可复现。对角移动使用归一化输入，不能额外获得 √2 倍速度。

## 连招、滞空与跳跃

五段普通攻击按接受的招式顺序循环：1 → 2 → 3 → 4 → 5 → 1。输入缓冲不能绕过前摇、有效窗口、恢复和受击取消。服务端决定是否接受招式、造成伤害及进度变化；客户端可以表现输入，但不决定伤害值或任意目标位置。

空中攻击可暂缓下落，但必须有独立硬时限，重复点击 J 不能无限续空。第五段结束、超时、受击、翻滚/技能取消、死亡和重开都需要正确恢复重力与移动模式。实际判定以角色碰撞体和攻击高度规则为依据；只把模型抬高不算躲过地面伤害。

翻滚方向取当前归一化面向，服务端校验冷却与可行动状态。奔跑/翻滚/空中连招的效果仅负责表现，不能额外施加伤害或改变客户端权威性。

## 本轮数值调整

普通敌人与 Boss 的生命、伤害和架势下调，以便测试新连招。Boss 基础生命改为单人 360，每额外一名参与者增加 180，二人 540、三人 720；人数边界仍钳制在 1～3。AI 补位参与本轮缩放，但不占真人网络连接席位。

这只是开发基准，不是已完成的平衡。敌方招式仍应具备可读前摇与可躲避窗口，不能用降低数值掩盖命中和动作同步问题。

## 具体动作与平衡

J五段依次为正斩、反斩、上挑、突刺、下砸，各有不同程序化姿态及网格轨迹。每段起手方向在该段动作内锁定，移动仍可继续；避免一边转身一边让实际攻击留在旧方向。最长输入缓冲0.32秒，超过0.65秒没有续段则结束连招；第五段后下一输入回第一段。空中链同次离地只能取得一次最长3.2秒悬停，落地才重置资格。L在地面或空中均可沿面向翻滚，持续0.35秒动作恢复、前0.18秒保护，空中翻滚不会重置下落速度或续空资格。

普通敌人：HP55、架势35、伤害8、架势伤害6、移速210、前摇0.30秒、攻击间隔0.85秒。Boss三招伤害12/14/20，预警增加10%，恢复阶段一1.6秒/阶段二1.15秒。三职业U冷却3秒，I冷却8/7/9秒，O冷却20秒；U是无能量消耗的可重复主动技，不是自动施放的被动。

新增UE测试源码覆盖五段连续点击（latent真实引擎帧）、空中取消及同次离地不续空、方向与双击奔跑、U/I/O严格能量流。未修改或回退全局GFrameCounter，没有通过关闭测试绕过验证。实际UE构建与执行仍未完成。
