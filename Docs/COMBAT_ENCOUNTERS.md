# 下一阶段：敌人战术与打击反馈

## 已有运行反馈与本轮范围

用户反馈上一版NPC可正常交互、剧情可以推进、敌人正常刷出。这是上述流程的用户实机反馈，不代表本轮新敌人、UE自动化、画面、音频、完整通关或三机联机已经通过。

本轮在既有三章路线中加入三种敌人职能、攻击名额、实体枪线预警、局部姿态停顿和原创合成音效，不增加第四章或复杂装备系统。

## 敌人及应对

| 职能 | 当前基准 | 行为与应对 |
|---|---|---|
| 近战兵 | 沿用HP55/架势35/伤害8 | 接近后0.30秒前摇，近战后恢复；路线航点追踪 |
| 盾役 | HP75/架势45/移速170 | 空闲且可行动时保护正前方±60°，生命伤害降至25%，架势伤害不减少；侧后或足够高的空中跨越不受保护，破势后2秒暴露 |
| 炉枪兵 | HP42/架势22/移速190 | 中距250–700cm蓄力，0.85秒后沿起手方向释放一次地面枪线；长度760、半宽48、脚底高度差≤90才命中，伤害10，恢复约0.8秒 |

枪兵预警使用实际网格，方向在蓄力开始固定；玩家可以用纵深位移、足够高度跳跃或翻滚无敌避开。受伤、硬直或被位移会取消蓄力，取消不产生释放计数。击发判定检查地形路径和视线，不是客户端提交伤害；表现为短能量射线，不声称有实体物理子弹。

枪兵过近时尝试退向合法路线，不会继续主动贴近一个不满足开火距离的目标。每个目标同时最多两个普通敌人占用进攻名额，包含前摇与恢复；死亡/结束释放名额，Boss不使用此名额池。

码头第一波只用近战教学，第二波少量盾/枪；工坊和水道混编，每波最多两名枪兵。现有全队缩放不变。角色类型由服务器配置和复制，客户端只读取表现。

## 表现与反馈

盾役增加大盾和厚肩，守势时亮盾、暴露时放下并变暗；枪兵增加长枪和背部炉罐，蓝橙配色。头顶提示区分职能。枪兵预警最多8个无碰撞实例，沿路线边界截断，跨低台时抬到沿线最高地面避免遮挡；实际可读性仍需渲染检查。

命中产生约40ms的局部姿态停顿，破势约70ms，单次上限100ms；停顿不改变世界/角色游戏时间、移动预测、攻击计时或伤害窗口，危险预警继续更新。命中镜头轻微冲击遵守CameraShakeStrength开关。当前不是正式骨骼动画顿帧系统。

## 原创音效与资源流程

SourceAudio包含6个原创确定性合成PCM16、单声道44.1kHz WAV：挥击、命中、破势/地面冲击、翻滚、技能和终极。源文件约0.18–0.95秒，峰值约-2.9dBFS，首尾有静音包络，附来源/哈希/RMS清单；不是录音、配音、音乐或成品拟音。

Scripts/generate_audio_sources.py --check会验证格式、确切生成字节、包络与清单。Scripts/create_audio_assets.py只在UE编辑器导入自有资产到/Game/Audio/Generated，并写当前报告。启动hook和Mac/Windows构建入口已接入导入与六资产验证，生成目录显式AlwaysCook。导入保存不能证明试听或打包声音正常。

音频从已确认的攻击/命中/翻滚/技能/枪击事件本地触发，不在输入预测和复制事件各播放一次；专用服务器不播放。每世界最多12个短音效估计预算，并有同类节流与距离过滤。这是本项目播放入口预算，不代表控制引擎总混音器。AlphaAudioVolume 0–1调本次会话的新音效音量，0静音后续cue；设置尚不持久化。

## 验证与待验收

七套纯规则共8825项，普通与UBSan均通过：战斗222、视觉320、AI784、操作1174、剧情510、布局5440、敌人战术375。音频源--check、Python/Shell语法与工程检查通过。

新增7项UE测试源码覆盖盾正侧/角色配置、破势暴露、枪线延迟/被击打断/跳跃纵深及墙体、近战自前摇、每目标攻击名额，合计45项UE用例未运行。

云端没有Unreal：本轮C++/UHT、音频导入API、播放质量、预警可见性、实际手感、三人混战与打包均未验证。Mac更新后用Build-Mac.sh编译并导入，再检查码头第二波及工坊混编；可用AlphaAudioVolume 0或CameraShakeStrength 0分别隔离音效/震动问题。

原始WAV按仓库规则使用Git LFS；更新后执行 `git lfs pull`。未安装时先安装Git LFS并执行 `git lfs install`，否则只有文本指针，不能被UE当声音导入。CI checkout已启用LFS。
