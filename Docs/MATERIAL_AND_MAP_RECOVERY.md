# 黑色材质排查与关卡重设计交付

## 已确认的代码问题与证据边界

此前生成材质是可选资源，缺失时静默退回引擎BasicShapeMaterial；调用代码却假定该材质拥有Tint/Color参数，并长期缓存找不到资产的结果。该路径不能保证角色/场景颜色，和用户截图的统一黑灰现象相符。没有本机shader/Python日志，不能把它断言为截图的唯一原因；平台shader失败、未生成资源或编辑器独立曝光仍需区分。

当前修正：运行时检查Tint/Glow/Atlas/FlatColor参数，缺失/旧版会有日志和屏幕提示，并允许5秒后重试加载；已经创建的回退MID需要重新进入PIE才能重建。`AlphaArtCheck`只报告资产和参数，不代表shader成功或画面验收。

## Mac 更新与首次启动

关闭正在运行的UE编辑器，在项目目录执行：

```bash
git pull --ff-only origin main
./Scripts/Build-Mac.sh "/Users/Shared/Epic Games/UE_5.6"
```

默认动作编译AlphaGameEditor，并调用UE Python生成材质/纹理，验证本次revision3报告和五个资产。`Test`参数可执行并检查本次UE自动化报告，云端没有实际运行Mac脚本。Windows使用README的Build-Windows.ps1，Build/Test/Art/Package均准备资源。

打开编辑器后，`Content/Python/init_unreal.py`会按源图与脚本指纹生成/刷新自有资产。等待材质编译结束，查看Python/shader错误后再Play。自动保存报告不能替代shader编译；同名手工资产不会被覆盖，需要先手工改名或复制。

## 颜色隔离步骤

在运行窗口的控制台依次使用：

```text
AlphaArtCheck
AlphaArtFlatColor 1
AlphaArtFlatColor 0
```

- Check显示MISSING/OUTDATED：先查看Python输出，完成生成再重启PIE。
- FlatColor1正常显示红/绿/金角色色，而正常模式过暗：优先排查光照、法线、曝光及反射；FlatColor不是最终美术模式。
- 参数ready但FlatColor仍统一黑灰：查看材质编译错误、实际绑定材质、平台shader及视口曝光。不能仅凭ready认为渲染正常。
- FlatColor关闭纹理/光照和镜面贡献，仍受曝光/色调映射影响。诊断命令只修改本项目表面MID，不改变伤害或技能特效。

## 原创贴图与实际接入

`SourceArt/Anime/T_AnimeSurfaceAtlas.png`是本轮实际生成的原创1254×1254彩色四格贴图，清单记录SHA-256、尺寸和用途。四格依次为木板、石材、青瓷、红布。按sRGB/Color采样导入，使用内缩UV避免相邻格串色；图并不保证绝对无缝。

地板、栏边、青瓷、帆布、箱子和衣料按用途引用；人物皮肤和能量不采样Atlas。衣料织纹约15–18%，保留原职业配色。该图是生产纹理，不是实机截图或正式人物模型；当前仍没有正式手工骨骼模型与完整音效。

## 地图本轮变化

专门关卡设计子智能体先完成 `LEVEL_REDESIGN_PLAN.md`，评审后才编码。参考同类作品的遭遇推进、窄宽节奏和前中后景原则，不复制其地图或资产。

- 码头：货场、窄栈桥、泊船台，真实30cm低装卸台。
- 工坊：锻造厅、偏侧装卸廊、独立炉厅，主炉移动到后段。
- 水道：桥头、中央桥、不对称前后灯庭，取消重复三组大拱。

共享数据生成非矩形真实地板、外边界与可见面，没有旧整块隐形底板填住桥外缺口。主路不强制跳跃，没有落水、移动平台或高台谜题。

开始战斗后沿HUD目标前进；存活真人进入420cm范围且全队含倒地成员位于1100cm内，再由服务端开遭遇。AI不能独自触发。后续遭遇不会在远端照计时自动刷怪。AI/普通敌人/Boss、镜头、合法出生与地图数据同步；回NPC路径不锁死。胜利后的AI继续救援与跟随，避免唯一真人倒地时无法回NPC确认。
