# 程序化工坊美术：实现与使用

本轮把单色灰盒推进为有统一形体和配色的程序化美术。没有 Unreal 实际渲染截图；本文描述代码与素材，而非已验证的画面品质。

## 已落地

| 领域 | 变化 |
|---|---|
| 场景 | 黑铁/青瓷/黄铜工坊，炉心、铜环、柱梁、管道、灯笼、塔楼与齿轮构成多层背景；战斗地面保留较高可读性 |
| 角色 | 每名约 19～20 个网格组件组成头、躯干、四肢、衣甲与武器；三职业有肩甲、机关背包、衣摆和灯环差异；Boss 为炉甲巨锤轮廓 |
| 动作表现 | 程序化步态、衣摆、武器蓄力与挥动；受击闪白、破势金色、倒地暗化；不替代骨骼动作 |
| 特效 | 斩击、重斩、轨迹、聚怪、灯域、共鸣、受击与救援使用本地临时网格；单世界最多 24 个效果，每个最多 24 片外层与 24 片表面亮带，共 48 个实例 |
| 镜头 | 根据复制的队伍位置与 Boss 平滑取景，支持宽高比变化；轻量受击震动可用 `CameraShakeStrength 0` 关闭 |
| 界面 | 暗青面板、黄铜描边、职业色生命条、架势条、紧凑目标信息与独立 Boss 血条 |
| 材质 | 统一 Tint/Metallic/Roughness/Glow 主材质生成脚本、原创细节与法线纹理；未在当前环境生成 UE 资源 |

环境使用 13 个实例化网格/材质批次，当前布局 416 个装饰实例；这不是实测 draw calls。装饰无碰撞、无导航影响，原有地板和四周碰撞边界保留。专用服务器不创建环境、角色视觉或效果。

## 资源生成

原始资源：

- `SourceArt/Surfaces/T_ForgeDetail.png`：256×256 细节数据，非 sRGB。
- `SourceArt/Surfaces/T_ForgeNormal_N.png`：256×256 切线空间法线。
- `SourceArt/Surfaces/manifest.json`：来源说明与 SHA-256。
- `Scripts/generate_surface_textures.py`：只依赖 Python 标准库，可重现相同 PNG；不需要下载素材。

执行 `Build-Windows.ps1 -Action Art` 会在 UE5.6 编辑器命令行运行 `create_art_assets.py`：

1. 检查目标资产是否属于本生成器，拒绝覆盖同名未标记资产。
2. 导入两张纹理，设置线性数据和法线压缩。
3. 建立 `/Game/Art/Materials/M_AlphaSurface`，连接底色细节、金属度、粗糙度、法线和自发光。
4. 保存纹理与材质，为本次进程写入独立 JSON 报告。
5. 包装脚本确认报告与五个磁盘包存在；`Package` 自动先做此步骤。

材质由 `/Game/Art` AlwaysCook 规则保留；引擎基础形体也显式纳入 Cook。两个编辑器插件不会作为游戏运行依赖。

生成器会刷新自己标记的资产。需要手工调整时先复制到其他名字，避免下次生成覆盖。此主材质为不透明材质：Glow 只控制发光，特效消失依靠亮度和尺寸，不能把 Alpha 当作透明渐隐。

## 回退与验证边界

缺少生成材质时，运行代码使用引擎 BasicShapeMaterial。几何与 Color 仍然有表现，但金属、粗糙、法线和 Glow 不会凭空生效。不能把回退模式当作完整美术效果。

本机已验证原始 PNG 的结构、CRC、尺寸、SHA-256 与生成可重复性，并检查 Python 语法。没有执行 Unreal Python API、材质编译、Cook、渲染或 GPU 性能采样。

在引擎中验收时先运行 Art 生成，再检查：

1. 战斗区域没有因炉火曝光或特效遮挡而失去可读性。
2. 三角色脚底、胶囊与地面吻合；头部、武器和衣摆无严重穿插。
3. 攻击取消后不再播放待发刀弧，光弧不夸大命中范围。
4. 客户端镜头包含其他队友和倒地玩家，超宽屏及跳跃不截断动作。
5. 关闭 Bloom 后预警仍可辨认；低画质、打包程序能加载材质。
6. 三人最复杂战斗下采样帧时间、阴影和绘制成本，按目标硬件调整。

正式手工角色、骨骼动画、精修场景、Niagara 与声音仍在后续制作范围。艺术基准与审查详见 `ART_DIRECTION.md`、`ART_REVIEW.md`。

最新日本热血战斗动漫方向、独立发光材质、角色轮廓和地面冲击见 `ANIME_COMBAT.md`。旧阶段记录不代表新版本已完成实机验收。

最新资源管线为revision3，新增原创四格彩色Atlas和编辑器自动生成；黑色材质排查及Mac一键入口见 `MATERIAL_AND_MAP_RECOVERY.md`。旧回退材质不保证Tint支持，不能声称缺少生成材质仍有正确角色色彩。
